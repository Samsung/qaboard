QA-Board keeps improving. Release notes tell you what changed, in a few lines, without digging into commits.

## The "What's new" dialog
When QA-Board is updated with new release notes, the web app shows a **What's new in QA-Board** dialog **once**, when the page loads. It shows the highlights of the release notes published since your last visit.

- Close it with **Got it** (or <kbd>Esc</kbd>): it won't show again for those notes.
- **See all changes** opens the full release notes.
- Only notes from the last ~60 days pop up: if you're new, or back from a long vacation, you won't get a pile of old news.

:::note
What you've seen is remembered **by your browser**. In another browser, on another computer or in a private window, the dialog shows up again.
:::

## Reading the release notes anytime
Open the **What's new** side panel from:
- the **What's new** button (sparkles icon) in the header of the left sidebar, next to the docs icon. A dot on it means there are notes you haven't read yet;
- the **What's new** link in the footer of every page;
- the **What's new** button on the projects list (the home page).

The panel lists all the release notes, newest first. Notes you haven't seen yet are tagged **New**. Use the **search box** to find when something changed, e.g. "history", "filter" or "admins".

:::tip
The link `https://<your-qaboard>/#whats-new` opens the panel directly, from any page. Handy to point colleagues to a new feature in a chat.
:::

## What's in a release note
Each release note covers a month (or a quarter, or a year, for older history):
- a **short summary**, for busy readers;
- **highlight cards** for the most important changes, each tagged for who it matters to (**Users**, **Project leads** or **Admins**), with a **Learn more** link to the docs;
- **All changes**, the details per area: *Web app*, *CLI and project setup*, *Server and administration*, *Documentation*, *Fixes*. In the panel, click **All changes** to expand them.

## The full archive
All release notes are also on the docs website, at [Release notes](/release-notes). Follow them in your feed reader with the [RSS](pathname:///release-notes/rss.xml) or [Atom](pathname:///release-notes/atom.xml) feeds.
