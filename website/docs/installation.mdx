sidebar_label: Client Installation
---

You need to install QA-Board's CLI client: `qa`. It wraps and runs your code.

### Open-source (default)
```bash
pip install qaboard
```

### SIRC users
```bash
pip install --upgrade git+ssh://git@gitlab-srv/common-infrastructure/qaboard
pip install --upgrade 'qaboard-site-sirc @ git+ssh://git@gitlab-srv/common-infrastructure/qaboard#subdirectory=deployments/sirc/cli"'

```

### DSK users
```bash
# same with the repo URL you have access to
pip install 'qaboard[dsk]'
```

The extras installs auto-configure defaults such as the API URL, port, and other site-specific settings. You do not need to manually set environment variables for standard deployments.

:::tip
Environment variables (e.g. `QABOARD_HOST`, `QABOARD_PROTOCOL`) **always override** site package defaults. This lets you point at a different server during development or testing without changing the installed package.
:::

To make sure the installation was successful, try printing a list of `qa`'s CLI commands:

```bash
qa --help

# If you get errors about not using a utf8 locale, you can likely:
#   export LC_ALL=C.utf8 LANG=C.utf8
```

## Connecting to a custom QA-Board server
If you installed `qaboard` without a site extra (or want to override the defaults), set these environment variables:

```bash
export QABOARD_HOST=my-server:5151
export QABOARD_PROTOCOL=http
```
