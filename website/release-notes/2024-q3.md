## Web app
- The tuning form has a bigger editor, a nicer layout, and defaults to the `linux` platform.
- The web app checks your session with the server instead of trusting what the browser remembers.
- Errors about missing project permissions are shown on the commits list.
- Better contrast, and tooltips are back.

## CLI and project setup
- `qa` starts faster: imports are delayed, and it no longer makes a network request on every call to check for updates.
- `qa batch` accepts several `--tuning` and `--tuning-filepath` options, merged together. String or list values go into a `_config` key whose items are appended to `context.configs`.
- Batch YAML files can set default `platform` and `configurations` for all their batches, like `database`.
- Batches without an `inputs` key match more inputs, including the database folder itself, and empty batch definitions now get a warning.
- Fixed duplicated inputs in batches.
- Fixed unstable output directories when redoing runs started from the web app.

## Server and administration
- The docs explain how to develop with docker, and `/docs` on the server now leads to the docs.

## Documentation
- The docs website moved to Docusaurus 3, and search results link correctly when the docs are served by the web app.
- The [user management](/docs/backend-admin/user-management) page documents project access restrictions.
