## Web app
- Upgraded the UI toolkit to Blueprint 5, with refreshed tooltips, popovers and notifications.
- Integrations now come from the selected batch's configuration when it has its own, show their errors more clearly, and appear on the commit index page again.
- Metric tags are clearer, shown as compound tags.
- Configuration differences with nested items are now displayed correctly.
- The file viewer has an icon for PNG files, says when there is no reference, and collapsing/expanding/selecting files works again.
- Disabled the image viewer's buggy full-page button.

## CLI and project setup
- Input metadata keys starting with `_` are no longer stored with runs.
- Fixed bit-accuracy checks wrongly falling back to plain file comparisons.
- Fixed permissions of artifact folders created from Windows.

## Server and administration
- Backend workers no longer restart all at the same time.
- Exports name crops better, and no longer strip more characters than intended from file names.

## Fixes
- Fixed errors when users have no email.
