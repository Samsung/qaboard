## Web app
- The image, video and bit-accuracy viewers can now compare raw/hex images by their image metadata and pixel-data hash, when the manifest has them, instead of the file hash.
- Layout tweaks for small and wide screens.

## CLI and project setup
- The `qaboard` package is now version 1.0.2.
- Auto-optimization: clearer errors when the objective cannot be computed, logs reachable from the web app even when the first iteration fails, and a `QA_SEED` that now seeds every random generator.
- `qa check-bit-accuracy` prints clearer logs, with links to the failing comparisons.
- Windows paths are now converted case-insensitively and with forward slashes.

## Server and administration
- Upgraded the Cantaloupe image server from 4.1 to 5.0.
- PostgreSQL now allows 200 connections, with more working memory per query.
- The backend has configurable memory limits and `UWSGI_CHEAPER_OVERLOAD` to tune how quickly workers are spawned.
- The cleanup job reads commits in chunks, using much less memory on large databases.

## Fixes
- Fixed crashes when the reference lacks a metric present in the new run.
- Fixed crashes of the history page and of some project index pages.
- Fixed the detection of raw and hex image files.
- Fixed tuning forms that were sometimes disabled for no reason.
