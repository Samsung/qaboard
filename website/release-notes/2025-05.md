## Web app
- Hover the colored dot of an automatic region of interest to see its diff value.

## CLI and project setup
- The deprecated `qatools` package still ships for older scripts, and importing it now shows a deprecation warning: use `qaboard` instead.

## Server and administration
- The backend image installs its dependencies with uv from `backend/uv.lock`.
