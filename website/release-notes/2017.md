## Web app
- Added a searchable list of commits. Each commit page shows the results on every input: metrics, curves, rendered videos and the parameters used.
- Added an interactive view of the estimated trajectories, and support for ground truth to compute error metrics such as drift.
- Commit pages show their git branch, and load faster thanks to caching.

## Server and administration
- The app follows the CI's git-based output folders, and can be served with uWSGI behind nginx.

## Notes
- QA-Board started in September 2017 at Samsung as a small internal Flask server, built to debug the results of a computer-vision (SLAM) pipeline faster. The ideas that shaped the product were already there: one page per commit, a reference to compare against, and rich visualizations of each output.
