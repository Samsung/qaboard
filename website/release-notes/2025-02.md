## Web app
- Output cards keep a minimum height while they load, so scrolling a long list no longer starts loading too many images at once.
- The reference image's label always shows the image size.
- Upgraded to React 18, Redux 5 and recent Blueprint and Plotly versions.

## Server and administration
- The backend now uses a redis service as a shared cache, with `REDIS_HOST` and `REDIS_PORT` (included in `docker-compose.yml`). Each worker warms the cache when it starts.
- Asking for a full commit hash that has no results now fails right away with a 404, instead of a slow search.

## Fixes
- Fixed an error when hovering an image while the diff image is hidden.
- Fixed a server error when a run was reported without any extra data.
- Fixed small display issues in the metrics, tables and tuning forms after the upgrade.
