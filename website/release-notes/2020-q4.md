## Web app
- Added a batch menu to redo only the failed runs. Redoing deleted outputs also redoes pending runs.

## CLI and project setup
- `qa` works in git worktrees.
- Matrix batches can add configurations on top of the batch's base configurations.
- Database paths are normalized to avoid common mistakes, and relative database paths are kept relative.
- File names with special characters are handled better.

## Server and administration
- The cleanup script has a `--can-delete-artifacts` option to delete artifacts even when the project doesn't enable it.
- Subprojects no longer require GitLab, and aggregating metrics no longer fails on bad metrics.
- The API code is split into files with clearer roles, and some pages are faster.

## Documentation
- The installation docs explain how to connect the CLI to a remote QA-Board server with `QABOARD_HOST` and `QABOARD_PROTOCOL`.

## Fixes
- Fixed file permissions when saving artifacts or running from Windows.
- Fixed bit-accuracy checks.
