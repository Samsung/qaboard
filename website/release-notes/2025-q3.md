## Web app
- The batch selector marks milestone batches with a star, and works better with the keyboard.
- On commits with many outputs, the controls panel shows how many outputs it has read options from, with a "Refresh Options" button to update them all.
- The "Delete All Runs" menu item says more clearly that it deletes the runs in all other projects for this commit.

## CLI and project setup
- `qa batch` fails with a clear error when a batch in `batches.yaml` is not a mapping (with `inputs`, `configurations`...), and warns about batches with an empty definition.
- Set `QA_BATCH_FILTER_INPUT_REGEX` to only run the inputs of a batch whose path matches a regular expression.

## Server and administration
- Commit pages use less memory on the server, and a commit that is missing from the database returns a clean 404.
- The nginx image builds again: it now uses the Debian archive since Debian Buster reached its end of life.
- The backend image builds its XML libraries from source to avoid library version mismatches. If SAML support can't load, the backend now starts anyway and logs a warning.
- For contributors, `development.yml` runs the backend with `uv run` and as your own user.

## Documentation
- The [batches](/docs/batches-running-on-multiple-inputs) page uses the new `qa batch first-batch second-batch` syntax.

## Fixes
- Fixed "Copy reference image to the clipboard", which copied the new image instead of the reference.
