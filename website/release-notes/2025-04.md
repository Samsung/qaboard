## Server and administration
- The server updates the "latest results" time of commits and projects at most every few seconds, which avoids database lock contention when many runs report their results together.

## Fixes
- `qa run` no longer crashes when writing the outputs manifest fails, it only warns.
- Fixed `qa optimize` crashing when it sets `QA_OPTIM_DIR`.
