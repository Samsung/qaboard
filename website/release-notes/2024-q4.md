## Web app
- The image viewer shows both images' dimensions when they differ, and warns when some tiles fail to load.
- Logs link directly to the LSF log when LSF killed the run.
- Clearer error messages when tuning is not possible, and when an export folder is not writable or has locked-down permissions.
- Style and help text improvements.

## CLI and project setup
- `exclude` filters can match the input path relative to the database with `rel_input_path`.
- `QA_BATCH_TIMEOUT` sets the timeout of local runs, and `QA_BATCH_QUIET` stops `qa batch` from printing each run's command and output directory.
- `qa check-bit-accuracy` sets `QA_BATCH`, so batch-only metadata logic behaves as in `qa batch`.
- When the server cannot report run statuses, `qa batch` warns and falls back to reading the output folders.
- Fixed batch aliases, batches named `matrix`, and `*` input patterns.

## Server and administration
- The local sign-up endpoint is enabled again, unless you set `QABOARD_DISABLE_SIGNUP=True`.
- API tokens are stored in a new table (with a migration).
- Batch summaries are counted in the database, using less memory, and file exports are faster.
- Output folders created by the server are now writable by all users (umask 0), avoiding permission issues when runs write to them.
