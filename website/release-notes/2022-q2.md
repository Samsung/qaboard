## Web app
- Commit pages now accept a branch name instead of a commit ID, and show the latest commit of that branch.
- Logs now load only when you scroll to them, and use the same run headers as the other views.
- Stand-alone Plotly `.html` figures are now shown side by side with the reference.
- "Copy to clipboard" on an output directory now copies a decoded path.

## CLI and project setup
- The Jenkins runner now retries failed requests, and the server retries when checking Jenkins build statuses.
- Fixed deadlocks when a tuning pipeline's runs themselves call `qa batch`.
- Fixed spurious warnings when the first batch of a commit starts without a git hosting provider configured.
- Git errors now print the failed command's output.

## Server and administration
- The image server keeps its logs in rolling files with a 30-day history, instead of storing them forever.
- Deleting data now also removes the empty directories left behind.
- Fixed duplicated CORS headers on API responses.

## Fixes
- Fixed an edge case in the dynamic output viewer where no file ended up selected.
- Fixed the cleanup job failing on deleted commits, and returned proper errors for unknown commits.
- Fixed encoding errors in the backend when it runs as a non-root user, and several Jenkins integration errors.
