## Web app
- `is_failed` metrics are now shown, including for failed runs.
- Wider sections on wide screens, clearer error messages, and no more empty tooltips.

## CLI and project setup
- Runs now get the batch label as `QA_LABEL`, and their QA-Board ID as `context.id`.
- Configurations can be `null`.
- Redoing a run from the web app now reuses the original output directory.

## Server and administration
- The backend image now uses Python 3.11 on a newer OS.
- The web app is built with a multi-stage Dockerfile, for faster builds and smaller images. Compose files pick the development or production target.
- The bundled Cantaloupe image server is no longer started by the default docker compose setup, in favor of an image server running separately.
- The backend trusts every git repository it clones (`safe.directory`), avoiding errors with recent git versions.

## Fixes
- Fixed errors when the reference output was deleted.
- Fixed "same data" being shown too often in the file viewers.
