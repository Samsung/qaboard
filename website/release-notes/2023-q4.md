## Web app
- The output menu shows the run's compute time (for example "1h2min3s"), and offers to copy or open the reference's output directory, in titled sections.
- The date range filter no longer needs both a start and an end date.
- Deleting several batches skips milestones and batches that no longer exist.
- Tuning warnings are shown as callouts, and more errors are displayed instead of failing silently.
- Fixed state issues when the URL contains encoded characters.

## CLI and project setup
- `qa check-bit-accuracy` compares RAW and HEX images by their attributes and pixel data, and warns and falls back to file hashes when attributes are missing.
- Batches can change labels while their runs are ongoing.
- Fixed submodule projects that used their parent's repository, and errors when LSF jobs had already finished.

## Server and administration
- Git pushes no longer create commits ahead of time, which bloated the database of monorepos with hundreds of projects. Commits are recorded with their configuration and metrics when their first batch is posted.
- New projects work whether their default branch is `main` or `master`.
- Supports GitLab 16 sign-in.
- Database JSON columns now use JSONB (with a migration).
- The web app can report errors to Sentry with source maps and send product analytics to PostHog. Both are optional, enabled with build arguments.
- pgAdmin is served under `/pgadmin4/`, and Flower can display pickled task data.
- The docs and the dev setup now use `docker compose` instead of `docker-compose`.
- Fixed race conditions in the image pixel API and when creating inputs, and errors when deleting the same run twice.
