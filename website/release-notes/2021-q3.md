## Web app
- The reference image is hidden when it is identical to the new one.
- When selecting a region in the image viewer, the copied region of interest now includes the image dimensions.
- Tuning plots ignore non-numeric metric values, and falsy values are no longer shown as 0.
- Plots keep their colors when the data doesn't change, and the layout is more responsive.
- Tags look nicer.

## CLI and project setup
- Paths to batches files, including `inputs.batches`, can use `{project}` and `{subproject}`.
- Auto-optimization uses a fixed random seed by default, so experiments are reproducible. Set `QA_SEED` to change it.
- The Jenkins Windows runner prints the job's console output.
- Clearer messages when inputs are not found, and auto-optimization logs are saved at the right place.
- Stopping an LSF job that already finished no longer fails.

## Server and administration
- Triggering Jenkins jobs is more robust, with a timeout and clearer errors, and integrations always provide a link to the job.
- Deleting outputs handles corrupted output manifests.

## Documentation
- Documented run parameters and badges, and how to select regions of interest in the image viewer.
- Updated the LSF and "running your code" docs.

## Fixes
- Fixed timezone issues in the commit list.
- Fixed subprojects with relative paths, and permission issues.
- Fixed tuning forms with recursive configuration tags.
- Fixed the image viewer when an image doesn't exist in the reference.
- Fixed deleting an output's files when some files are to be kept: the whole output folder could be removed.
