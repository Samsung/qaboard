## Web app
- Pixel values shown when you hover an image are now read from the file actually displayed (the TIFF when it is used), and always match the pixel under the cursor. They could be off by one pixel before, especially at the image's edges.
- In the "Output Files" view, opening a TIFF or a PNG also falls back to the other format on the side (new or reference) that doesn't have it.
- Build status icons are clearer: a clock while a build is queued or pending, a spinning icon while it runs, and a pause icon only for blocked or stuck builds.
- Integration links inside sub-menus are now checked too, so broken links show up there like in top-level menus.
- Saving, editing or deleting a shared milestone now requires being logged in. Milestones saved before this change have no owner: any logged-in user can still edit them, and becomes an owner by doing so. Milestones show their commit's author as a tag.

## Server and administration
- Added `services/vips`, a small Docker image with the libvips command line tools, to convert PNG outputs to TIFF.

## Fixes
- The loading spinner of the image viewer now disappears once the images are loaded, including for the reference image and for images already in the browser's cache.
- Jenkins builds triggered from the commit page are now polled for their status. Before, their status could stay stuck after the trigger.
- Integrations with the same name in different menus no longer share their status.
- When `qa` reports a commit the server can't find, the server answers with a clear error instead of crashing.
