## Web app
- The diff viewer is hidden when both files are identical, and the reference video is hidden when it is the same as the new one. Video sync is less strict.
- The commit list date range can be set in the URL with `?from=YYYY-MM-DD&to=YYYY-MM-DD`, and no longer jumps around.
- Batch logs show the ID of each command, and concatenate the commands of a tuning batch.
- Better link to the docs.

## CLI and project setup
- Matrix batches support indexing, like `${matrix.param[0]}` or `${matrix.param[key]}`.
- The CLI shows nicer tracebacks, and better messages when runs are killed, for instance by LSF.
- `qa batch` always prints the URLs of the results, and warns when batches files are empty.
- Bit-accuracy checks handle non-default output directory names, long paths, and several reference folders with results.
- The CLI handles network errors, not only HTTP errors.
- The Jenkins integration no longer requires `JENKINS_AUTH` to be set.

## Fixes
- Fixed `qa get`, including `qa get output_dir`.
- Fixed imports when not running under a QA-Board project directory.
- Fixed commit messages with two line breaks, `None` batches and relative database paths.
- Fixed deleting artifacts of subprojects, and interpolating `{subproject}` in the web app.
- Fixed output manifests on Windows.
