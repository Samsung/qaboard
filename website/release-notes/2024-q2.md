## Web app
- The image viewer shows a spinner until both images are fully loaded.
- Plotly figures are shown side by side with the reference by default.
- Integrations can use the reference commit as a variable (`ref_commit`).
- Fixed the histogram when there is no reference, with clearer legends.

## CLI and project setup
- Tuning parameters and configurations containing single quotes now work when tuning from the web app.
- In batch matrices, values that are valid JSON (lists, objects...) are now parsed instead of being kept as strings.
- GitLab commit statuses are retried a few times before giving up.
- `qa check-bit-accuracy` stops early when nothing was compared.
- Fixed `--reference-label` in some cases, and Windows UNC paths when computing output directories.
