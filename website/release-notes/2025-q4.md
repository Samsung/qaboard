## CLI and project setup
- `QA_BATCH_FILTER_INPUT_REGEX` now matches anywhere in the input path, and ignores a leading `^`.

## Server and administration
- The backend image is now based on Debian trixie with Python 3.13, which also brings fixes for the XML libraries used by SAML login.

## Fixes
- On Windows, the CLI uses Git for Windows' `ssh` when it is installed to fix the permissions of outputs on network storage, since the built-in `ssh` can't read keys from network paths. Paths with spaces are quoted correctly.
