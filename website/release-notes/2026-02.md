## Server and administration
- Added a database index on outputs (`idx_outputs_batch_user_storage`) that speeds up the storage quota dashboard. New databases get it automatically; on an existing database, create it by hand.

## Fixes
- The image and text viewers' keyboard shortcuts (e.g. `t` to toggle between new and reference) no longer fire while you type in a text area or an editable field, or when you press Ctrl, Cmd or Alt combinations such as Ctrl+C.
- The "Quota" entry in the commit list's menu opens the current storage dashboard again. It pointed to a dashboard that was deleted.
