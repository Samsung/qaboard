## Web app
- The output directory's copy button now offers both the Linux and the Windows path.
- Images of different resolutions but the same aspect ratio now stay synced when zooming and panning.
- Image views now always check the reference, so they can tell you when both images are identical.
- Errors in the `path` of visualizations are now shown on the output card.

## CLI and project setup
- During auto-optimization, runs get `QA_OPTIM_DIR`, a directory to save data relevant to the whole optimization loop.
- The LSF runner retries sending a job a few times before failing.

## Server and administration
- The backend image now includes the libraries needed for SAML login.

## Documentation
- New page on [monorepos and subprojects](/docs/monorepo-subprojects): `root: true`, inheritance with `super`, and `include`.

## Fixes
- Fixed copying the current region of interest in the image viewer.
- Fixed spurious errors on output cards.
