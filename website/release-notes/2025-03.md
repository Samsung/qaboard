## Web app
- The image viewer's zoom controls fade out faster, and the sidebar's menus close sooner after the mouse leaves them.

## Server and administration
- Production deployments can forward the logs of the backend, database and redis containers to a fluentd log collector.
- PostgreSQL now writes its logs to files and logs connections and disconnections, and accepts up to 200 connections.
- Larger request headers are accepted (`buffer-size` 65535), and big uploads are buffered so they don't block a worker.

## Fixes
- Fixed the diff image after the upgrade of the image viewer library.
- HTML and Plotly viewers no longer stay blank when a file fails to load.
- Fixed the visualization options (such as the frame selector) sometimes not appearing after the move to React 18.
- Fixed a server error on some commit pages.
