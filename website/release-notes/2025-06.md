## Web app
- The image viewer's filters have a new panel with value displays, a reset button and a new Sharpen filter, next to Brightness, Contrast and Gamma.
- In the bit-accuracy viewer, hover a file's size to download the new or the reference version of the file.
- The filter box of the controls panel also filters the list of metrics.
- Redesigned sidebar, with a user menu that shows who you are logged in as and lets you sign out.
- You can search the sidebar's list of [integrations](/docs/triggering-third-party-tools), and menus keep their state when you close and reopen them.

## CLI and project setup
- Runner settings are merged in this order, each winning over the previous: the `runners` section of `qaboard.yaml`, the input type's `runners`, the batch's runner settings, then the flags you pass explicitly to `qa batch` such as `--lsf-queue` or `--local-concurrency`.
- `--local-timeout` and `runners.local.timeout` now set the timeout of local runs, not only `QA_BATCH_TIMEOUT`.
- Removed `qa batch --lsf-fast-queue`: LSF jobs always use the regular queue.

## Documentation
- The [inputs](/docs/inputs) page shows how to set runner settings per input type.

## Fixes
- Fixed the CLI when it is embedded in a C++ program and has no command-line arguments.
