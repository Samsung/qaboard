## Web app
- When matching runs with the reference, the web app and exports now prefer reference runs with the same input path.
- Stopped batches now mark their interrupted runs as failed, with finer-grained statuses.

## CLI and project setup
- `qa batch --action-on-existing skip` no longer skips runs that are still pending: it waits for them instead.
- The LSF runner no longer uses `fast_queue`: jobs always go to the configured `queue`.
- Absolute input paths are resolved through symlinks.
- The package now depends on `scikit-learn` instead of the deprecated `sklearn` name.

## Server and administration
- The public sign-up API endpoint is disabled, to prevent unauthorized users from creating accounts.
- The login settings are baked into the web app image when it is built.
- nginx forwards the `X-Forwarded-*` headers that SAML needs, and the development setup can run over HTTPS.
- The cleanup job falls back to deleting the whole output directory when a run has no file manifest.

## Documentation
- The [server setup](/docs/deploy) page documents user management, sign-in methods and the new login variables.

## Fixes
- Fixed a directory traversal vulnerability in the nginx configuration for the docs.
- Fixed regions of interest when the image is zoomed, and the text copied from the ROI viewer.
